# C1 Design

从当前锁文件出发，候选命令为 cargo update -p rustls --precise 0.23.45。先确认依赖约束与MSRV，版本可解析后保持最小传递闭包。若该版本另有更新安全公告，重新研究兼容补丁并说明选择，不机械锁死已知有问题版本。

无需新增应用层TLS机制，不把公告描述扩大为已复现攻击。一次重算锁文件后用locked检查验证。保留现有 HTTP 单测覆盖（重试、重定向、附件错误、token脱敏）。

风险：传递依赖变更可能影响 MSRV 或目标平台。根manifest更改只有在解析器证明必要时允许；大版本/语义变化属于需重审范围。回滚旧lock恢复已知风险，不能作为发布完成。

长期安全门约定由C4写回质量规范；C1将依赖树、公告与检查记录写回父任务research，注明五套工具共享。
