# Zotero 开启时可靠读取条目信息与本地 PDF

## 目标

保持 Zotero 打开，用户凭题名或 citation key 找到一篇文献，或凭关键词、主题词、标题片段、期刊名取得一批候选，再读取选中文献的信息和本机 PDF。已知 Zotero item key 时可以直接读取。CLI 与 skill 使用同一套查询、歧义和错误语义。

## 已确认的背景

- Windows 本机安装的是 Zotero 10.0.7，安装包配置主库使用连接级独占锁。单独的只读 SQLite 连接可能一直等到 Zotero 退出。可重复实验和命令入口见 design.md。
- 当前 item get、item children、item pdf 都依赖临时快照。doctor 探测本地 HTTP 可达性，但这些查询未消费该能力。关闭桌面后的宿主机 doctor 已验证 SQLite 可读。原失败时的持锁者和具体操作没有现场记录。

## 要求与验收

- [ ] R1 开启桌面并允许本机通信，在独占锁保持期间从既有命令完成 item get → item children → item pdf --pages 1。输出匹配目标库已提交的字段、笔记、附件关系和已知 PDF 页文本。命中桌面读取时零 SQLite 快照尝试，不支付 5 秒重试。覆盖已有用户库及 group:<id> 语义。
- [ ] R2 关闭 Zotero 后，默认命令仍从指定数据目录创建一致快照。用同一套固定数据对照两条路径的 JSON、空结果、错误和 PDF 选择规则；不足以产生兼容结果的请求必须显式说明。
- [ ] R3 Zotero Local API 只向 loopback 发 GET；可选 Better BibTeX 插件仅允许本机只读查询 RPC（HTTP POST，见 design.md）。访问正确库并区分目标库不匹配、目标条目不存在、API 禁用、PDF 未落盘和提取后端不可用。不得因 404、身份冲突或文件缺失去别的库取同名 key，不请求写授权、不走 Web、不修改源库、WAL 或附件；CLI 自有临时文件和既有 PDF 缓存可用。
- [ ] R4 doctor 单列 SQLite 快照与桌面读取，给出本命令能用的路径以及对应的下一步；skill eval 覆盖 SQLite busy + HTTP 可读、403 + busy、关闭桌面、已知 key + 本地 PDF。不能把可达的探针当作条目或 PDF 已读取成功。
- [ ] R5 交付隔离回归测试和一次真实 Windows 桌面读取记录。分开记录程序版本、调用路径、是否有快照尝试及结果，不保存真实条目正文、PDF、凭据或库标识。真实验收未执行时单独列为待验。

- [ ] R6 输入完整或部分题名，个人库与指定群组均可从候选继续到 R1。唯一完整题名可自动选取；同名或只有部分匹配时列出题名、作者、年份和 item key，不能默认取首条。无命中给出空结果。
- [ ] R7 library citekey 在目标库内精确匹配原生 citationKey、旧 Extra 行和可用的 Better BibTeX 记录，再按 item key 读取。重复来源指向同条目则去重；大小写不相等、前缀相似均不冒充精确命中。不同条目冲突给出候选；区分未找到、插件不可用和来源无法验证。
- [ ] R8 关键词或主题词可在题名、摘要、标签中召回候选；标题片段支持批量查找；按期刊查找须核对刊名或期刊缩写。包含摘要提及同一刊名但发表于别刊的反例、跨页结果、默认排除回收站和附件的用例。显示有效分页、匹配总数或明确的未完成状态。主题检索范围为库内字段的词项匹配。

## 范围

优先验收题名与 citation key 单篇定位，然后验收偶尔使用的批量查找，以及选中条目后的只读流程。本轮排除剪贴板/UI 选中项自动检测、语义扩展与向量索引、workspace/RAG、引文导出、远程文件下载及新增写操作。现有搜索参数如未适配桌面路径，必须保留明确的兼容处理，不可忽略参数。
